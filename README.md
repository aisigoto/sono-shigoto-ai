# その仕事、AIにでき？｜サイト初期実装

静的HTML/CSS/JSで作った初期版です。

## 含まれるもの
- トップページ
- AI仕事診断（5問・ブラウザ内で完結）
- 最初の記事
- About / Privacy / Contact の仮ページ
- robots.txt / sitemap.xml

## 公開前に変更するもの
1. `YOUR-DOMAIN.example` を実ドメインへ変更
2. 問い合わせフォームを実サービスへ接続
3. プライバシーポリシーを実際の利用サービスに合わせて確定
4. Search Console / Analytics を設定
5. ASP登録後、比較記事のアフィリエイトリンクを設定
6. 料金・機能等の事実確認日を記事管理に追加
